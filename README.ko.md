# 🌱 Seed

아이디어를 심으세요. 중요한 것을 키우세요.

**[English](./README.md) | 한국어**

Seed는 막연한 아이디어를 간단한 대화만으로 명확하고 실현 가능한 계획으로 키워주는 터미널 도구입니다. 코딩을 몰라도 되고, 완벽한 아이디어가 없어도 시작할 수 있습니다. 지금 생각하고 있는 것을 말하면, Seed가 아이디어가 준비될 때까지 한 번에 하나씩 쉬운 질문을 던집니다.

준비가 되면 Seed는 그 대화를 실제 문서로 바꿔줍니다: 제품 기획서, 기술 개요서, README, 그리고 Claude Code, Cursor, Codex 같은 AI 코딩 도구에 그대로 붙여넣을 수 있는 작업 지시서까지 만들어줍니다.

**Seed는 여러분의 프로젝트 코드를 절대 작성하거나 수정하지 않습니다.** 질문하고, 메모를 남기고, 요청할 때만 문서를 만들 뿐입니다.

## Seed를 써야 하는 이유

- **개발자가 아니어도 됩니다.** Seed는 전문 용어를 피하고, "범위"나 "실현 가능성" 대신 사람·상황·결과에 대해 묻습니다.
- **한 번에 질문 하나씩.** 20개짜리 설문지도, 긴 글벽도 없습니다. 그냥 대화입니다.
- **아무것도 사라지지 않습니다.** 모든 답변, 시도했던 방향, 내렸던 결정이 로컬에 저장되고 언제든 다시 볼 수 있습니다.
- **언제든 되돌릴 수 있습니다.** 가지치기한 아이디어는 삭제되지 않고 언제든 복구할 수 있습니다.
- **솔직한 피드백을 줍니다.** 무조건 칭찬하지 않고 모순과 빈틈을 짚어줍니다.
- **오프라인에서도 동작합니다.** AI 계정이 없어도 됩니다 — 별도 설정 없이 쓸 수 있는 내장 로컬 모드가 있습니다.

## 설치

```bash
npm install -g @seed-cli/seed
```

설치 없이 한 번만 써보려면:

```bash
npx @seed-cli/seed "친구한테 답장하는 걸 까먹지 않게 도와주는 앱"
```

[Node.js](https://nodejs.org) 20 이상이 필요합니다.

## 시작하기

지금 생각하고 있는 것을 그대로 말해보세요:

```bash
seed "친구한테 답장하는 걸 까먹지 않게 도와주는 앱"
```

Seed를 처음 실행하면 어떤 언어를 쓸지(영어 또는 한국어), 그리고 어떻게 생각할지 — 연결된 AI 계정을 쓸지, 아니면 별도 설정이 필요 없는 Seed의 내장 오프라인 모드를 쓸지 — 물어봅니다. 두 설정 모두 나중에 `seed config`로 바꿀 수 있습니다.

이후에는 Seed가 묻는 질문에 답하기만 하면 됩니다. 명령어를 외울 필요는 없습니다 — Seed와 대화하는 중에 `/branch`, `/bloom`, `/harvest` 같은 명령을 입력해 워크플로의 다른 부분을 바로 시도할 수 있고, `/help`를 입력하면 무엇을 쓸 수 있는지 볼 수 있습니다.

## 아이디어가 자라는 과정

| 단계 | 명령어 | 하는 일 |
|---|---|---|
| 🌱 심기 | `seed "아이디어"` | 한두 문장으로 새 아이디어를 시작합니다 |
| 💧 성장 | `seed grow` | 집중 질문에 한 번에 하나씩 답하며 아이디어를 다듬습니다 |
| 💧 관점 공급 | `seed water` | 여러 관점(사용자, 가치, 첫걸음, 첫 순간)에서 아이디어를 바라봅니다 |
| 🌿 가지 뻗기 | `seed branch` | 원본을 잃지 않으면서 아이디어가 갈 수 있는 여러 방향을 탐색합니다 |
| ✂️ 가지치기 | `seed prune` | 첫 버전에 담기엔 너무 큰 부분을 미뤄둡니다 (삭제되지 않습니다) |
| ☀️ 현실 검증 | `seed sunlight` | 실제 사용자, 대안, 제약에 비춰 아이디어를 검증합니다 |
| 🌸 개화 점검 | `seed bloom` | 아이디어가 만들 준비가 됐는지, 아직 불명확한 게 뭔지 확인합니다 |
| 🍎 수확 | `seed harvest` | 준비가 되면 아이디어를 실제 문서로 만듭니다 |

이 순서를 반드시 따를 필요는 없습니다 — `seed bloom`이 다음에 무엇을 더 살펴봐야 할지 항상 알려줍니다.

## 아이디어를 문서로 바꾸기

아이디어가 어느 정도 단단해졌다면 (`seed bloom`으로 확인해보세요) 수확해보세요:

```bash
seed harvest idea      # 한 장짜리 아이디어 카드
seed harvest brief     # 짧은 프로젝트 요약
seed harvest prd       # 완전한 제품 요구사항 문서
seed harvest trd       # 기술 요구사항 문서
seed harvest readme    # 프로젝트 README
seed harvest prompt    # AI 코딩 도구에 바로 쓸 수 있는 작업 지시서
seed harvest all       # 위 전부를 한 번에 생성
```

모든 수확 결과는 프로젝트 폴더의 `.seed/harvest/`에 저장되며, 같은 수확을 다시 실행하면 기존 파일을 덮어쓰지 않고 새 버전(`prd-v1.md`, `prd-v2.md`, ...)을 만듭니다. Seed가 아직 모르는 내용은 지어내지 않고 `TBD`로 표시합니다.

`prompt` 문서는 AI 코딩 도구가 프로젝트를 대신 만들어주길 원할 때 특히 유용합니다 — Claude Code, Cursor, Codex 같은 도구에 그대로 넘기면 됩니다.

## 여러 아이디어 관리하기

서로 다른 폴더에 아이디어를 여러 개 심어뒀다면, `seed garden`이 전부 보여주고 원하는 걸로 바로 이동할 수 있게 해줍니다:

```bash
seed garden
seed garden 2          # 목록의 두 번째 아이디어 열기
```

지금 당장은 다룰 수 없지만 잃고 싶지 않은 아이디어가 있다면:

```bash
seed wither            # 아이디어를 잠재우기 (삭제되지 않습니다)
seed wake              # 나중에 다시 깨우기
```

아이디어에 있었던 모든 일 — 모든 질문, 가지, 결정 — 을 보고 싶다면:

```bash
seed history
seed tree              # 아이디어와 그 방향들을 시각적으로 보여주는 지도
```

## 내 AI 연결하기

Seed는 기본적으로 내장된 로컬 로직만으로 완전히 오프라인에서 동작합니다 — 계정이나 API 키가 필요 없습니다. 더 자연스럽고 날카로운 질문을 원한다면 AI 프로바이더를 연결할 수 있습니다:

```bash
seed config
```

짧은 설정 마법사가 뜨고, 다음 중 하나를 고를 수 있습니다:

- **OpenAI** — 계정으로 로그인하거나 API 키 사용
- **Google Gemini** — API 키
- **Anthropic Claude** — API 키
- **커스텀 프로바이더** — OpenAI 호환 API라면 무엇이든 (OpenRouter, Groq, 직접 운영하는 모델 등)
- **로컬 fallback** — 설정 없이 오프라인으로 동작

API 키는 항상 환경변수에서만 읽고, 절대 디스크에 저장되지 않습니다. 언제든 프로바이더를 바꿀 수 있고, 요청이 실패하면 Seed가 항상 오프라인 모드를 안전망으로 유지합니다.

```bash
seed config list        # 현재 설정 확인
seed config test        # 활성 프로바이더가 제대로 동작하는지 확인
seed config use openai  # 프로바이더 전환
```

## 언어

Seed의 인터페이스는 기본적으로 영어입니다. 한국어를 쓰려면:

```bash
seed --lang ko
# 또는
SEED_LANG=ko seed
```

`seed config set lang ko`로 언어를 영구적으로 설정할 수도 있습니다. 아이디어를 어떤 언어로 입력하든 Seed는 질문하고 문서를 쓸 때 그 언어를 따라갑니다 — 인터페이스 언어와 아이디어의 언어는 서로 독립적입니다.

## 내 데이터는 어디에 저장되나요?

Seed가 아이디어에 대해 아는 모든 것은 프로젝트 안의 `.seed/` 폴더에 저장됩니다 — 평범한 JSON과 마크다운 파일이며, AI 프로바이더를 연결하지 않는 한 어디에도 숨겨지거나 전송되지 않습니다. 이 폴더 밖의 어떤 것도 Seed가 건드리지 않습니다. Seed는 여러분의 소스 코드나 다른 프로젝트 파일을 절대 수정하지 않습니다.

## 명령어 목록

```text
seed [아이디어]        새 아이디어를 심거나, 진행 중인 아이디어를 이어갑니다
seed grow             집중 질문으로 아이디어를 키웁니다
seed water [관점]      다른 관점에서 아이디어를 탐색합니다
seed branch           독립적인 방향을 탐색합니다
seed prune            핵심이 아닌 범위를 가지치기합니다
seed sunlight         사용자와 대안에 비춰 현실을 검증합니다
seed evolve           아이디어의 다음 세대를 만듭니다
seed decide           명시적으로 내린 결정을 기록합니다
seed bloom            아이디어가 얼마나 준비됐는지 확인합니다
seed tree             아이디어와 가지들을 봅니다
seed history          지금까지 있었던 모든 일을 봅니다
seed harvest [유형]    idea / brief / prd / trd / readme / prompt / all 문서를 생성합니다
seed garden           주변 Seed 프로젝트를 보고 엽니다
seed wither           현재 아이디어를 잠재웁니다
seed wake             잠자던 아이디어를 다시 깨웁니다
seed restore          가지치기한 가지나 항목을 복구합니다
seed config           AI 프로바이더와 언어를 설정합니다
```

모든 명령어에 `--help`를 붙이면 옵션을 볼 수 있고, 스크립트에서 Seed를 다룬다면 `--json`으로 기계가 읽기 쉬운 출력을 받을 수 있습니다.
